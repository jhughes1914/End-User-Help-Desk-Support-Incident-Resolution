# Mock Ticket ID: HD-1042
Priority: Medium
Category: Access / Login Issue
User Impact: Single User

## Issue Description:
User unable to log into Windows workstation after multiple failed attempts.

## Troubleshooting Steps:
- Verified user identity
- Checked account status in Active Directory
- Identified account lockout due to failed login attempts
- Reset password and unlocked account

## Resolution:
User successfully logged in after password reset.

## Root Cause:
Repeated incorrect password entry.

## Prevention:
Provided guidance on password requirements and lockout policy.


# SOP: Password Reset & Account Unlock
Purpose: Restore secure user access efficiently

## Steps:
- Verify user identity
- Open Active Directory
- Locate user account
- Unlock account and reset password
- Force password change at next login
- Confirm successful authentication

## Security Notes:
- Never share passwords verbally
- Follow least-privilege principles
