# End User Help Desk Support Incident Resolution



# Project Summary:

Delivered front-line IT support for multiple organizations, resolving end-user incidents related to hardware, software, access, and peripherals. Focused on fast resolution, clear communication, and consistent documentation.



# Responsibilities:

- Provided Tier 1–2 support for Windows desktops, laptops, printers, and peripherals

- Diagnosed and resolved hardware/software issues using a structured troubleshooting methodology

- Performed Active Directory password resets and account unlocks

- Escalated unresolved issues appropriately after root cause analysis

- Communicated technical issues clearly to non-technical users



# Technologies & Tools:

- Windows OS

- Active Directory

- Printers, scanners, peripherals

- Basic ticketing and issue documentation

- Results & Impact

- Restored system access and functionality with minimal downtime

- Improved user satisfaction through calm, professional support

- Reduced repeat incidents through proper resolution and user education
